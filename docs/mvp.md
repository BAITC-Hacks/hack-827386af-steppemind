# Требования MVP

Основание: предоставленный PDF кейса, страницы 1–6. Этот файл описывает целевой продукт, а не готовую реализацию.

## Обязательные возможности

- Конструктор: свободное описание, проверка полноты, минимум 3 уместных уточняющих вопроса, редактирование и ручное подтверждение карточки.
- Карточка: название, контекст, потребность, пользователи, данные, ограничения, ожидаемый результат, критерии успеха, контакт и формат взаимодействия.
- Рейтинг: 0–100, расшифровка баллов, недостающие сведения, пересчёт после подтверждённого изменения.
- Каталог: все опубликованные задачи доступны всем командам; сортировка по рейтингу; фильтры по теме и готовности.
- Отклики: команда отправляет идею, план, срок и ссылку на прототип; число откликов не ограничивается.
- Решение бизнеса: ручное принятие или отклонение предложений, допускается выбор нескольких команд или отказ всем.
- Минимум одна содержательная AI-функция. При недоступности API допустима локальная заглушка с показом промпта, входа, выхода и обработки некорректного ответа.

ИИ не добавляет неизвестные факты. Результат редактируется и подтверждается человеком до публикации. Рекомендации не ограничивают общий каталог. Автоматическое назначение команд и использование чувствительных признаков участников исключены требованиями кейса.

## Рейтинг готовности

Рекомендованная в кейсе шкала, которую предлагаем взять для первого MVP:

| Критерий | Баллы |
| --- | ---: |
| Контекст и потребность | 20 |
| Данные и материалы | 20 |
| Ожидаемый результат | 15 |
| Измеримые критерии успеха | 15 |
| Ограничения | 10 |
| Пользователи | 10 |
| Контакт, консультации и обратная связь | 10 |
| Всего | 100 |

Баллы начисляются только за заполненные и подтверждённые сведения. Конкретные правила проверки достаточности и частичных баллов ещё предстоит выбрать; одного непустого текста недостаточно для оценки качества.

| Баллы | Готовность |
| --- | --- |
| 0–39 | Черновик / требует уточнения |
| 40–69 | Рабочая |
| 70–89 | Готовая |
| 90–100 | Приоритетная |

Уровень «черновик» в рейтинге не равен неопубликованному состоянию карточки. Подтверждённая опубликованная задача доступна даже при низком рейтинге; отклик разрешён на любом уровне.

## Данные для демонстрации

Если организаторы не выдали набор, подготовить синтетические данные:

- 5 черновиков разной полноты с отраслью и исходным описанием.
- 5 карточек со всеми полями рейтинга и текущим баллом.
- 5 команд с названием, интересами, навыками и технологиями.
- 5 предложений с командой, идеей, планом, сроком и ссылкой.

## Границы

Кейс не требует полноценной регистрации, восстановления пароля, сложных ролей, чата, уведомлений, календаря, файлового хранилища, обучения модели, векторной базы, мобильной адаптации и производственной инфраструктуры.

В полном сценарии упомянуты баллы командам за подтверждённый этап. Для обязательного демо достаточно отклика и решения бизнеса; полный проектный трекер не требуется. Механику баллов командам можно добавить после основного сценария, не начисляя их за один факт отклика.

## Приоритеты оценки

Сквозной сценарий — 20; качество карточки — 15; геймификация бизнеса — 25; каталог и отклики — 15; AI-функция — 10; техническое качество — 10; демонстрация — 5. Всего 100 баллов.

Для сдачи нужны исходники, запускаемый MVP, README с запуском, архитектурой, формулой рейтинга, правилами каталога и тестовыми сценариями, а также демонстрация до 5 минут.
